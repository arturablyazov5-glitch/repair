# Иллюстрации (TASK-010, Иннокентий)

Это 27 самостоятельных SVG в `media/illustrations/`. Внешних ресурсов и шрифтов нет, текста внутри нет. Цвета взяты строго из палитры `css/base.css`: `#0d5c6b #d9ecee #f2a33a #fdf0d9 #eaf3f4 #14181f #e4e1da #f3f1ec #fff`. Стиль у всех один: плоские формы, контур `#14181f` (3 px на 480/640/960, 2,5 px на 320), фон `--bg-tint`, мягкий круг `--brand-soft`, сетка точек и янтарная акцентная деталь. Во всех категориях есть сквозной янтарный значок с ключом. У содержательных файлов есть `role="img"` и `<title>/<desc>` с уникальными id (префикс = имя файла), поэтому их можно вставлять и inline. У трёх декоративных файлов стоят `aria-hidden="true" focusable="false"`. Вес каждого файла от 0,2 до 9,2 КБ.

Генераторы, рендер и контактные листы лежат в `agent-context/innokentiy/`: `gen_*.py`, `render.mjs`, `cat.png`, `steps.png`, `gal.png`, `all.png`.

## Как подставлять
Внутрь `.ph` кладётся `<img>`. Правило `.ph:has(> img)` из base.css само скроет подпись-заглушку, `object-fit: cover` уже задан:
```html
<figure class="ph ..." data-ph="..." style="--ar:4/3"><img src="{{root}}media/illustrations/washer.svg" alt="" width="480" height="360" loading="lazy"></figure>
```
Про `alt`: если рядом есть заголовок с тем же смыслом (карточки услуг, шаги процесса), ставьте `alt=""`. В галерее и hero нужен описательный alt, он приведён в таблице. Внутренний `<title>` при вставке через `<img>` скринридеру не виден.

## Замечания для прораба
- Иллюстрации в галерее временные, пока нет фото. Когда появятся реальные JPG из `media/MANIFEST.md`, нужно просто заменить `src`. Плитки 4 (диагностика посудомойки), 6 и 7 и пары «до/после» здесь не закрыты: «до/после» должны быть фото.
- Для вертикальных плиток (`--tall`, 2:3) 4:3-сцена обрезается по бокам. Если обрезка мешает, поставьте для этих img `object-fit: contain; background: var(--bg-tint)`.
- Все сцены рассчитаны на светлую тему. На `.section--dark` ставить только внутри светлой карточки.
- Перегенерировать всё: `cd agent-context/innokentiy && python3 gen_cat.py && python3 gen_steps.py && python3 gen_hero.py && python3 gen_gallery.py && node render.mjs "" all`.
