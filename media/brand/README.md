# Логотип «Сервис-Люкс»

Знак **«Скоба»**: буква **С**, собранная из трёх прямоугольных брусков, как фронт встраиваемой техники в нише, и квадратный **индикатор «готово»** в проёме. Знак строго геометричный, построен на сетке и одинаково держится на 16 px и на вывеске. Вордмарк «Сервис-Люкс» переведён в кривые из Onest (wght 700, трекинг −0.02 em), поэтому от загрузки шрифта не зависит.

## Файлы

| Файл | Назначение |
|---|---|
| `logo.svg` | основной: знак + вордмарк, для светлого фона (169.4 × 28) |
| `logo-light.svg` | для тёмного фона: белый, индикатор оранжевый |
| `logo-mono.svg` | монохром целиком в ink: печать, факс, гравировка, ч/б документы |
| `logo-mark.svg` / `logo-mark-mono.svg` | только знак (28 × 28) |
| `favicon.svg` | фавикон на сетке 32 (поле 1 px при 16 px). В тёмной теме браузера знак становится белым |
| `apple-touch-icon.png` | 180 × 180, тёмная плитка (iOS скругляет углы сам) |
| `og-image.png` | 1200 × 630 для соцсетей и мессенджеров |
| `header-snippet.html` | inline-фрагменты для шапки и подвала + CSS |

## Геометрия (сетка 28, модуль 2)

- Знак: `M0 0H28V6H6V22H28V28H0Z`, толщина бруска 6. Индикатор 8 × 8 в точке (20, 10), выровнен по правому краю брусков, зазоры сверху и снизу по 4.
- Вордмарк: высота прописных 14 (½ знака), центр прописных совпадает с центром знака, отступ от знака 10.
- Пропорции горизонтального логотипа: ширина ≈ 6.05 × высоты знака.

## Палитра

| Роль | Цвет |
|---|---|
| Ink (знак, текст) | `#0e1013` (`--ink`) |
| Paper | `#ffffff` (`--bg`) |
| Акцент: только индикатор | `#ff4f1a` (`--accent`) |

Оранжевым бывает **только** квадрат-индикатор. Если оранжевый недоступен (одноцветная печать, гравировка, факс), берите `*-mono.svg`. Градиенты, тени, обводки и фильтры не применять. Не перекрашивать С в оранжевый, не поворачивать знак, не менять трекинг и не отрывать индикатор от бруска.

## Охранное поле

Минимум **½ высоты знака** (на сетке 14 ед.) со всех сторон. В шапке это требование выполняется за счёт высоты 72 px и внутренних отступов контейнера.

## Минимальные размеры

| Вариант | Минимум |
|---|---|
| Знак + вордмарк | высота знака 20 px (экран) / 6 мм (печать) |
| Только знак | 16 px (фавикон, на 32-сетке пиксельно чёткий) / 4 мм |

Рекомендуемая высота знака: шапка 28 px (при скролле 24), подвал 40 px, OG/презентации от 56 px.

## Как вставлять

**Картинкой:**
```html
<img src="media/brand/logo.svg" width="169" height="28" alt="Сервис-Люкс">
```

**Inline (шапка, подвал):** возьмите разметку из `header-snippet.html`. Знак и вордмарк окрашиваются через `currentColor`, поэтому на тёмном фоне достаточно задать `color:#fff`. Индикатор берёт цвет из `var(--accent)`. Размер управляется одной переменной `--logo-h` (высота знака). Ссылке нужен `aria-label`, сами SVG помечены `aria-hidden`.

**Head:**
```html
<link rel="icon" href="media/brand/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="media/brand/apple-touch-icon.png">
<meta property="og:image" content="https://<домен>/media/brand/og-image.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="Сервис-Люкс — ремонт бытовой техники в Краснодаре">
```
Если нужен `favicon.ico` для старых браузеров, его можно собрать из `favicon.svg` (16 + 32).

## Исходники

Генераторы лежат в `agent-context/khariton/`: `wordmark.py` строит контуры из `fonts/onest-*.woff2` через fontTools-инстанс вариативного шрифта, а `build-brand.mjs` собирает все файлы и рендерит PNG через Playwright.
