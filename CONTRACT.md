# Контракт бригады · лендинг «Сервис-Люкс»

Статический сайт без фреймворков: HTML + CSS + vanilla JS. Сборка: `node build.mjs` склеивает `src/sections/*.html` (по имени файла) в `index.html`, `src/legal/*.html` — в `legal/*.html`. Просмотр: `npm run dev` → http://localhost:8080 (каждый агент может поднять на своём порту: `python3 -m http.server 80NN`).

## Заглушки
Нет данных (цены, сроки, ИНН, фото, имена мастеров, список «официальных» брендов, эндпоинт заявок) → ставь заглушку, видимо помеченную в коде комментарием `<!-- TODO: что нужно уточнить -->`, а на странице — нейтральный правдоподобный текст. Числа-обещания (сроки, суммы, проценты) — в формате «от X ₽» с комментарием TODO. **Никаких выдуманных фактов-«достижений»** («15 лет опыта», «10 000 ремонтов»): если нужен блок цифр, бери только реальные (73 отзыва, 44 пятёрки, часы работы, 4 остановки рядом) либо заглушки с TODO. Не называть себя «официальным сервисом бренда X», пока нет подтверждения: формулировка «работаем с техникой Bosch, Siemens…» + TODO «подтвердить статус авторизации».
Фото/видео: компонент `.ph` из base.css (см. файл). Реальные файлы позже подставим в `media/`. Логотипы брендов: **только по ссылке с сервиса trace-logos (не скачивать локально)**; точный URL-шаблон пока неизвестен → используй единственную JS-функцию/атрибут: `<img data-brand="bosch" alt="Bosch" loading="lazy">` + текстовый fallback-вордмарк (название бренда стилизованным текстом); `window.SITE.logoUrl(slug)` уже есть в `js/config.js`: возвращает URL с trace-logos.ru или `null` (тогда вордмарк). В каталоге trace-logos из нужных брендов есть только samsung, lg, xiaomi (+ whatsapp, telegram, max, yandex-maps, 2gis, sbp, mir, visa, mastercard) — у остальных (Bosch, Siemens, Miele…) логотипов нет, они остаются вордмарками. Агент «Лаврентий» пишет этот код, остальные логотипов не касаются.

## Дизайн
Светлая тема, токены в `css/base.css` (`--brand` бирюзово-синий, `--accent` янтарный, тёплый белый фон, шрифты Manrope/Inter). Используй только токены, а не «сырые» цвета. Классы base.css (.container .section .section__head .eyebrow .btn .card .chip .grid .field .input .consent .modal .ph .reveal …) — переиспользуй, **base.css не правь** (нужно что-то общее — напиши прорабу в отчёте). Свои стили — в `css/sections/NN-имя.css`, классы с префиксом секции (`.hero__title`).
Планка: «очень проработанный, много деталей» — не шаблонный лендинг. Тонкие градиенты и декоративные формы, inline-SVG иконки (свои, единый стиль: stroke 1.8, `.icon`), микро-анимации (reveal, hover, счётчики), табы/аккордеоны/слайдеры на CSS scroll-snap, аккуратные тени, реальная типографическая иерархия. Mobile-first: 320 / 768 / 1920 без горизонтального скролла и переполнений (особенно 992–1099). Доступность: контраст AA, :focus-visible, aria у табов/аккордеонов/модалок, `prefers-reduced-motion`. Без внешних библиотек (кроме шрифтов, уже подключённых). Картинок-файлов нет: графика — inline-SVG/CSS.
Пустой JS-файл не создавать; JS только если нужен, в `js/sections/NN-имя.js` (vanilla, без ошибок в консоли).

## Что для людей важно (из 73 отзывов — Яндекс Карты)
Хвалят (44×5★): конкретные мастера, которые приезжают точно в срок, быстро находят причину, **объясняют и показывают** («всё подробно объяснил»), не навязывают допуслуги; оригинальные запчасти и быстрый подвоз; умеют с премиум-техникой (Miele, Liebherr, V-Zug, Smeg, Bosch) — спасали после «мастеров с Авито»; доставка техники из ремонта; WhatsApp отвечает за полчаса; вежливые девушки на приёмке; удобная парковка; гарантийный ремонт; чинят «с гарантией».
Ругают (24×1★) — это **возражения, которые лендинг обязан снять честно**:
1. Платный выезд/диагностика 1500–3500 ₽, а ремонта нет → прозрачная цена диагностики, правила «когда зачёт в стоимость ремонта» (TODO подтвердить).
2. Тишина: «никто не позвонил», ремонт неделями, звонки без ответа → статусы в WhatsApp на каждом этапе, срок в договоре, ответ менеджера за N часов (TODO).
3. Грубость менеджеров, заявку аннулировали из-за непринятого звонка → вежливый регламент, подтверждение времени в WhatsApp, не отменяем без предупреждения.
4. Гарантийные ремонты: долгие ожидания запчастей, акты о возврате → честные сроки по гарантии, акты, что делать если срок вышел (закон о защите прав потребителей).
5. Завышенные цены на запчасти vs маркетплейсы, ошибки диагностики (плата 9000 вместо датчика) → смета до работ, артикулы запчастей и подтверждающие документы, согласование цены.
6. Нет доказательств состояния техники при приёмке («пылесос был грязный») → фото/видео фиксация при приёме, акт приёма.
7. Нет документов на руках / предоплата без результата → акт, чек, гарантийный талон; оплата после результата (TODO подтвердить условия).

## Правило ховеров (добавлено позже)
Ховер — только у интерактивных элементов (кнопки, ссылки, табы, чипы-фильтры, кликабельные карточки целиком, пункты аккордеона). Статичные информационные карточки/блоки/иконки/цитаты/цифры НЕ получают hover-подъём, тень, смену цвета и курсор. Класс `.card--hover` — только для карточки, которая сама является ссылкой/кнопкой. На тач-устройствах оборачивай в `@media (hover: hover)`. `:focus-visible` оставляем везде.

## Иконки: только Lucide (требование заказчика)
Свои нарисованные иконки не используем. Библиотека Lucide (lucide-static в node_modules, каталог иконок: https://lucide.dev/icons, имена в `node_modules/lucide-static/icons/*.svg`). Использование: `<svg class="icon" aria-hidden="true" focusable="false"><use href="#lucide-wrench"/></svg>` — сборка сама добавляет `<symbol id="lucide-wrench">` в спрайт на каждую страницу (ищет `lucide-<имя>` в src/ и js/). В JS-шаблонах пиши ту же ссылку `#lucide-<имя>`. Размер/цвет — через CSS (`.icon` в base.css: 1.25em, currentColor, stroke 1.75). Существующие спрайты `#ico-*`, `#sl-i-*` и inline-SVG иконки — заменить на Lucide. Логотип компании и логотипы брендов — не иконки (брендов — только trace-logos).
